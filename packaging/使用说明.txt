我密码呢 v{{VERSION}} 绿色版

使用方法
1. 解压整个文件夹。
2. 双击“我密码呢.exe”即可使用，无需安装。
3. 首次启动时，程序会在自身旁边创建 data 文件夹。

数据迁移
- 所有记录、图片、日志和备份都保存在 data 文件夹中。
- 移动到其他电脑时，请先关闭程序，再复制整个“我密码呢-v{{VERSION}}-绿色版”文件夹。
- 不要只复制 exe，否则原有记录不会一同迁移。

从“账页”旧版升级
- 先关闭新旧程序，再把旧版旁边的整个 data 文件夹复制到新版“我密码呢.exe”旁边。
- 不要同时运行指向同一份 data 的两个版本。

运行环境
- 仅支持 Windows 10 及以上 64 位系统。
- 系统需要 Microsoft Edge WebView2 Runtime；Windows 10/11 通常已自带或自动安装。

备份建议
- 使用程序右上角“数据交换”中的完整备份，定期创建加密 `.anb` 备份。
- 重要数据建议额外复制整个 data 文件夹到其他磁盘。
